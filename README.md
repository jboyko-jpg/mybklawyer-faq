# mybklawyer-faq

Animated whiteboard answers to the FAQ on https://www.mybklawyer.com (Law Offices of John M. Boyko).

- `index.html` – combined player for all ten FAQs (`?faq=N` opens question N, `?autoplay=0` disables autoplay)
- `faq1.html` … `faq10.html` – each FAQ as its own standalone animation

Self-contained HTML, no external dependencies. Served with GitHub Pages.
